# ⚙️ Run Locally

## Clone the project

```bash
git clone https://github.com/khaled1267/A6-Digitools-react-project.git
```

## Go to the project directory

```bash
cd A6-Digitools-react-project
```

## Install dependencies

```bash
npm install
```

## Start the development server

```bash
npm run dev
```
